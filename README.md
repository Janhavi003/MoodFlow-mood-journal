#  MoodFlow — Mood Journal Web App

A modern, minimal, and intuitive **mood tracking journal** built with React.  
Track your emotions, reflect daily, and gain insights into your mental patterns.

 **Live Demo:** https://mood-flow-mood-journal.vercel.app/

---

##  Features

###  Journal & Mood Tracking
- Select daily mood (Happy, Good, Neutral, Sad, Angry)
- Write journal entries with tags
- Clean, distraction-free writing interface
- Character counter

###  Analytics & Insights
- Mood trend visualization using charts
- AI-like mood predictions based on patterns
- Insight generation from journal entries

###  Productivity Features
- Daily streak tracking
- GitHub-style activity heatmap
- Recent entries overview

###  Authentication (Simulated)
- Signup & login system (LocalStorage-based)
- Protected routes
- User session persistence

###  UI / UX
- Modern SaaS-style design
- Glassmorphism UI elements
- Smooth animations (Framer Motion)
- Dark mode support 
- Premium typography (Iosevka)

---

##  Tech Stack

- **Frontend:** React (Vite)
- **Styling:** TailwindCSS
- **Charts:** Recharts
- **Animations:** Framer Motion
- **Routing:** React Router
- **State & Storage:** LocalStorage
